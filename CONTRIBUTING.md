# Contributing

Thank you for helping keep this list accurate. You don't need to code to help.

## Report a mistake or suggest an event

The quickest way is the **Email us** button on the landing page. If you use GitHub, open an issue with the matching template:

- **Wrong date, venue or link.** Include the event name and the organiser's page.
- **Suggest an event.** Include the organiser's registration page. We check it against the rules before adding it.
- **Suggest a source.** An event calendar, newsletter or Meetup group we should scan.

## Propose a rule change

The rules live in [`skill/ewai-event-scan/SKILL.md`](skill/ewai-event-scan/SKILL.md). Open a pull request or an issue that explains:

1. what you'd change;
2. which events it would add or remove (an example helps);
3. why it serves members better.

Rule changes that are merged get an entry in `RELEASE_NOTES.md`.

## What we won't accept

- Changes that make the assistant guess dates, prices or languages.
- Pitch nights, investor events, job fairs or online-only events. These are excluded on purpose.
- Anything containing API tokens or personal data.

Only the table owner writes to the Airtable table.
