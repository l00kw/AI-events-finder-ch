How to read the table

Connect

People talk to each other and no technical background is assumed: meetups, panels with an apéro, breakfasts, community nights.

Learn

Content first: conferences, talks, workshops and hackathons. For hackathons, the description says whether non-developers are welcome.

For

Who the organiser says it's for: Everyone, Business leaders, Founders, Product & UX, Developers, Researchers, Healthcare or Security professionals.

Link status

"Confirmed" means the link opened this event's registration page on the date shown. "Closed" means it was full or closed when we last checked.

How events are chosen

An AI assistant scans event calendars on a regular schedule. It follows a written rulebook, and a person reviews everything before it goes live. An event makes the list only if:

  • it takes place in person, in Switzerland;
  • AI is the main theme, not one panel inside a broader conference;
  • it is run in English (bilingual counts);
  • it isn't a pitch night, investor event, job fair, trade show or student-only event;
  • there is a working way to register.

Dates, prices and venues are taken from the organiser's own page. When something isn't published, the table says "TBC" rather than guessing. A missing event costs you little, but a wrong date costs you an evening, so we'd rather leave a field honest than complete.

Always check the organiser's page before you go. Events change, and our last check may be a few days old.

Want one for your country?

Everything that runs this list is open: the rulebook the assistant follows, the source list and the table design. You can copy it for another country or city.

  1. Copy the table. Create an Airtable base with the fields listed in the rulebook. Keep a public view that shows only approved rows.
  2. Adapt the rulebook. In skill/ewai-event-scan/SKILL.md, change the country, cities, sources and language rule to fit your community.
  3. Run it on a schedule. Add the rulebook as a skill in Claude and set up a scheduled task that runs it, or run it by hand when you need it.
  4. Review before publishing. The assistant only adds rows as "To review". A person approves or rejects every one.
